# Customer Support Agent

## Overview
Automated support agent for handling common customer inquiries, booking issues, and membership questions.

## Core Responsibilities
- Resolve booking confirmation issues
- Explain membership tiers and benefits
- Handle event-specific inquiries
- Escalate complex issues to human support

## Tech Stack
- Anthropic Claude 3.5 Sonnet
- Night Crew Chat UI
- Supabase for support ticket logging
